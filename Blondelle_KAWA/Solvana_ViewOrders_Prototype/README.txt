SOLVANA PHARMA — VIEW ORDERS HMI PROTOTYPE

HOW TO OPEN
1. Extract the ZIP archive.
2. Keep index.html, styles.css and app.js together in the same folder.
3. Double-click index.html to open it in Chrome, Edge or Firefox.
4. No server, installation, login or database is needed.

WHAT TO DEMONSTRATE
- Orders List: view all supplier-specific fictional orders.
- Search and status filters: test the interactive list.
- Order Details: click 'View details' on any row, then return.
- Alternative flows: use the 'DEMO CONTROLS' in the sidebar to show
  Access denied, System error and No orders available; Reset restores the list.
- Responsive: resize the browser or use mobile device emulation.

PROJECT NOTES
- All order data is fictional and stored locally in app.js.
- Access control and errors are simulated for UI demonstration only.
- This prototype does NOT implement secure authentication or a database.
- Scope: Supplier actor, View Orders use case, read-only access.
- Screenshots can be included in the PDF use case report.
